# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, argue about facts and sources rather than people, and assume good faith. Watch collecting has strong brand loyalties. Corrections are welcome from everyone, and a claim stands or falls on its evidence.

Report unacceptable behavior by opening a private security advisory on this repository or by contacting the maintainer through their GitHub profile. Reports will be handled confidentially.
